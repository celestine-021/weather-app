# Weather by Celestine

Weather by Celestine is a responsive React weather dashboard with live conditions,
hourly forecasts, and five-day summaries for cities around the world.

## Features

- View current conditions, hourly forecasts, and a five-day outlook for cities worldwide.
- Search for a city and switch between Celsius and Fahrenheit.
- Toggle between light and dark themes. Your theme preference is saved in this browser and restored on your next visit.

## Run locally

Install the dependencies, then start the development server:

```sh
npm install
npm start
```

The app uses the Open-Meteo geocoding and forecast APIs, so no API key is
required. An internet connection is needed for city search and live weather.
